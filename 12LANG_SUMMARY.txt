HOW TO USE
================================================================================

FOR END USERS:
  1. Login to Lingolion
  2. Open Settings (gear icon)
  3. Click "Change Language" button
  4. Select one of 12 languages
  5. Interface updates immediately
  6. Selection saved to your profile

FOR DEVELOPERS:

  Adding New Text:
    1. Add to frontend/locales/en.json
    2. Add translation to all 11 other files
    3. Use in HTML: <span data-i18n="key.name"></span>
    4. Or in JS: I18N.t("key.name")

  Getting Translation:
    I18N.t("nav.lesson_generator")  // Get text
    I18N.t("greeting", {name: "Ali"}) // With params

  Checking Current Language:
    I18N.getLang()  // Returns "fa", "en", etc.

  Applying to DOM:
    I18N.applyToDom()  // Updates all data-i18n elements
